# Träningsloggen

Träningslogg i helskärm för iPhone: program i dagar, pass med vilotimer, historik med kalender, rekord, kroppsmått och matlogg med streckkodsskanning.

Öppna https://georgeharoun9-dotcom.github.io/training/ i Safari och välj Dela → Lägg till på hemskärmen.

All data sparas lokalt på telefonen. Använd Program → Backup för att spara en kopia.
